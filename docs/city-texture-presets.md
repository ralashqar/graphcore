# City texture presets

V3 recipes optionally store textures.wall, textures.roof and textures.ground as allowlisted IDs. Omitted/none retains palette shading. Natural material colours override palette tint on selected surfaces. Glass, signs and trim retain separate materials. Wall roles currently use palette colour identity; ground uses low slab height and imported paving roles. This does not retexture city roads.

Eight CC0 ambientCG colour/roughness sets are hosted locally as 512px WebP, approximately 400KB combined. See public/city/textures/sources.json. No geometry displacement, normal-map downloads or live provider requests. Packed surface maps described below provide shading relief. Shared materials load selected maps lazily, use world-space triplanar mapping with mipmaps/repeat/anisotropy, and retain neutral shaded fallback until both maps load. No arbitrary texture URLs. Exported Quaternius wall/paving material roles are supported.

Branding > Surface textures provides independent wall, roof and ground selectors and swatches. Seeded demo designs exercise the collection. Palette-only remains available; existing saved recipes are unchanged. Saving reuses the existing ownership/revision/publication flow, with a matching strict server validator. No migration.

Local verification: TypeScript, build, Deno building-design schema tests, driving shader/browser checks, texture selector and mocked save/reload browser checks. Physical mobile performance and hosted publication remain unverified.

Texture repeats are enlarged fourfold for street-level readability: brick repeats every 5 world metres, concrete every 12, and other materials every 8. Colour and roughness use the same scale on procedural and Quaternius surfaces; roads are unchanged.

Optional wallBorder and groundBorder IDs separate Quaternius trim and plot/enclosure edges from primary surfaces. Omitted/primary inherits the primary texture; none uses the palette. Demo borders always select a distinct explicit material. Local save/reload and strict schema coverage include inheritance. Shared contract rollout requires the same City Edge/frontend/world-worker staging pair; worker city-design-3.6. No migration or production deployment.

Surface shading now packs source CC0 displacement (R) and roughness (G) in one lossless 512px Surface map. It replaces the runtime roughness image: still two maps and six triplanar samples per fragment, shared by instanced batches. Derivative bump perturbs normals without geometry displacement, fading out with distance/pixel footprint. Metal uses 0.65 metalness; other surfaces retain dielectric highlights controlled by source roughness. Glass remains separate. No new recipe fields or server deployment required for this shading update.

Quaternius native materials: decorator export v2 retains authored colour/normal/metallic-roughness maps and original UVs for solid surfaces. Offline resize bounds every embedded image to 512px (6.2MB complete pack); native normal intensity is reduced to 0.35 and maps are shared with the cached pack. Original / palette selects native materials on kit parts, palette colours on procedural parts; explicit texture IDs still override primary/border roles. Demo facade finishes use native wall and trim by default. Fake interiors remain simplified glass. Rebuild with Blender scripts/build-city-decorators.py, then node scripts/optimise-city-decorators.mjs (includes Pillow resize). No server contract change.

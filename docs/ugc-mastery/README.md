## What This Folder Is For

This is not a folder of copied articles. It is a distillation layer for:

- what makes UGC and short-form ads hold attention
- what makes them convert
- how repeatable viral formats are structured
- how to translate those ideas into GraphCore presets, scripting rules, and prompt guidance

## What This Folder Is Not For

This folder does not try to validate every operator claim as scientific fact. It treats the supplied articles as practitioner heuristics and turns them into design guidance that is useful for GraphCore's current architecture.

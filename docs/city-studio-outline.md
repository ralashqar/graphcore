# Construction outline sculpting

The opt-in City construction studio has **Sculpt outline** in Shape. Select a block part first. Green grips pull an exposed wall, or switch Pull to **Bay** to move a short section. Amber grips cut a corner inward; choose **Bevel** or **Recess**. The outline snaps in 0.5 m steps. A translucent wall preview responds immediately, while a throttled worker preview replaces the building with its actual wall bays, openings and roof during a held drag. The latest prepared result wins; an invalid edit keeps the last valid preview. Escape cancels. Each completed gesture is one undo step.

The authored part remains a separate volume. A pulled rectangle becomes a bounded simple polygon, which can be concave. The same polygon boundary feeds the union footprint, exterior wall bays, floors, roofs and collision preparation. Cardinal source edges retain their earlier anchor direction, so existing paint, openings and details follow the face when its length changes. A bevel or recess receives new edge IDs and can receive its own treatment. Spots resolve against the bay containing their saved face coordinate after bay counts change. Concave roofs first triangulate the outline, then clip each convex piece against roof planes; the original fast clipping path remains for ordinary convex buildings.

The tool supports simple parts with 3–12 edges. It rejects self-intersections, collapsed edges and plot-boundary crossings. Recesses are square corner cuts; Bay moves a roughly 2 m central section of an exposed face. Only exposed faces show grips. Bay mode conservatively refuses a source wall with authored paint, openings, attachments or the primary entrance, and explains why; whole-wall pulls retain those anchors. Arbitrary freehand vertices, multiple sequential recesses beyond the 12-edge limit, and sculpting elliptical or subtractive parts remain outside this pass. The precise box width/depth fields and quarter-turn shortcut are hidden for polygon parts to avoid invalidating authored vertices.

Rooms → Draw wall shows a live full-height wall ghost with approximate tile seams and an inline reason when its endpoint is invalid. It also sends valid held drags through the same throttled detailed preview, so the real partition appears before release without saving a gesture on every pointer move.

Verification: `cityStudioOutline.test.ts` covers snapped whole-wall and bay pulls, bevels, concave recesses, source anchors, façade infill, joined unions and the upper floor slab. `cityStudioRoofs.test.ts` covers a recessed roof for all ten families. The browser scripts `city-studio-outline-browser.mjs` and `city-studio-interiors-browser.mjs` check that a detailed preview arrives during a held drag, then cover save/reload and undo/redo. Desktop Edge and WebGL2 outline flows passed locally. A 60-sample warm CPU resolver benchmark measured p95 2.5 ms for the café, 7.5 ms for the townhouse and 5.4 ms for the courtyard apartment; it excludes worker transfer and GPU display. A local native Edge driving run measured 16.9 ms p95 across 72 properties. The 400-property run had a 16.7 ms median but a 450 ms p95 streaming hitch, so that release gate remains unresolved. These are single development runs, not a controlled before/after comparison. Physical touch controls remain unverified.
